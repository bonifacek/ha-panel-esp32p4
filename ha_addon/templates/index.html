Voice notifications

When a Home Assistant entity changes state, the ESP32 panel speaks the defined text through the ES8311 speaker. Requires speaker enabled on the panel and a TTS engine Piper (or other WAV) in HA.

Active Entity State: from State: to Text to speak
No rules. Click "+ Add rule" to start.
Typical state values
person / device_tracker
home — at home
not_home — away
binary_sensor / switch / light
on — on / detected
off — off / clear
lock
locked — locked
unlocked — unlocked
alarm_control_panel
armed_away — armed
disarmed — disarmed

The "State: from/to" field accepts * as any state. Example: from * to not_home triggers the rule every time the entity changes to not_home.
